# Cross-Platform Test Checklist

## Windows Editor
- Open project in Unity 6000.0.43f1.
- Run EditMode tests.
- Press Play in the gameplay scene.
- Confirm player, enemies, shielded enemies, and boss behavior.

## WebGL
- Switch platform to WebGL.
- Build project.
- Launch build in browser.
- Confirm game loads, keyboard input works, and no browser console blockers appear.

## Mobile
- Switch platform to Android or iOS.
- Build development player.
- Run on device or emulator.
- Confirm input method, screen scaling, and gameplay readability.

## Evidence To Capture
- Build result screenshot or log.
- Test run screenshot.
- Browser/mobile console logs for failures.
- Ticket IDs for any issues found.
