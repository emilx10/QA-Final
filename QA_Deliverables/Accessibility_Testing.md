# Accessibility Test Checklist

## Input
- Confirm keyboard-only play is possible.
- Confirm mobile input is reachable and does not require precision taps if mobile UI is enabled.

## Visuals
- Confirm enemy bullets, player bullets, shielded enemies, and boss are visually distinguishable.
- Confirm background effects do not hide active gameplay objects.
- Avoid rapid flashing VFX patterns.

## Readability
- Confirm HUD/menu text, if present, is large enough at common desktop and mobile resolutions.
- Confirm text does not clip or overlap.

## Motion
- Confirm boss and background movement are not excessive.
- Provide stable camera behavior with no sudden shake unless optional and brief.

## Known Follow-Up
- Add explicit color-blind friendly shield visual treatment if shield VFX is added later.
- Add remappable controls if the project expands beyond the assignment scope.
